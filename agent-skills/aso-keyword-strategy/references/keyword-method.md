# 关键词决策方法

## 相关性门槛

在考虑热度前回答以下问题；任何一项为“否”，都应排除或隔离该词：

1. 已验证产品能否满足搜索者的合理预期？
2. 商店页面能否真实解释这种匹配？
3. 通过该词进入的用户是否可能完成核心行为？
4. 使用该词在法律和合同上是否安全？

## 意图分类

| 分类 | 含义 |
|---|---|
| Direct | 描述核心任务或结果 |
| Feature | 描述已支持能力 |
| Audience | 描述目标用户或收藏类型 |
| Adjacent | 需求相关但主要任务不同 |
| Navigational | 品牌、产品、发行商或竞品名称 |
| Irrelevant | 偶然的字面或排名重合 |

## 证据解释

- 多个相关竞品覆盖同一精确词，支持市场存在，不证明产品匹配。
- 提供方高分只表示其量表内的关注度，不代表真实月搜索量。
- 低量但高意图的词仍可归为 `core` 或 `supporting`。
- 精确词未出现但产品匹配强时，可以归为 `experimental`。
- 品牌和 IP 词进入元数据前，必须具备明确权利或获批政策。

## 冷启动分配

优先组合：

- 直接核心概念
- 有依据的相邻入口概念
- 精确功能概念
- 少量实验词

不要写死比例，应根据现有证据解释分配。

## 第一方数据升级

进入 M3 后增加：

- 当前自然排名及观察日期
- 可用的搜索曝光或产品页浏览
- 与自然量分开的付费搜索词表现
- 在可归因时，按来源区分转化和后续激活

保留原始冷启动假设，便于团队比较预测与结果。
