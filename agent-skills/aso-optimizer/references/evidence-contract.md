# ASO 证据契约

## 证据等级

针对每项结论评级，不要对整个文件统一评级。

| 等级 | 含义 | 典型依据 |
|---|---|---|
| A | 直接第一方观察 | 官方后台/导出包含 App、市场、指标和时间范围 |
| B | 可复现的市场一致信号 | 多个相关竞品或独立来源结论一致 |
| C | 单一来源市场信号 | 单个提供方、竞品、快照或图表 |
| D | 产品驱动假设 | 符合已验证产品事实，但缺少市场验证 |
| U | 不受支持 | 缺失、矛盾、无法验证或超出材料范围 |

A 级不代表因果关系，只表示该观察在限定范围内具有权威性。

## 数据阶段

| 阶段 | 可用材料 | 允许输出 |
|---|---|---|
| M0 | 无已验证产品背景 | 仅问题和背景模板 |
| M1 | 仅产品背景 | 种子假设和收集计划 |
| M2 | 有竞品/市场证据，无第一方表现 | 冷启动建议和验证计划 |
| M3 | 第一方证据及产品背景 | 基线比较、诊断和实验 |

## 结论结构

每项重要结论写为：

```text
结论：
等级：
适用范围：
证据：
反向证据：
限制：
验证方式：
```

## 兼容规则

- 仅比较相同关键词、商店地区、平台且日期足够接近的排名。
- 保留提供方原生分数，并标记提供方与量表。
- 没有明确模型时，不得根据分类排名推算下载。
- 不得根据关键词排名推算转化。
- 不得仅根据前后时间关系推断因果。
- 不得用平均排名代替需求。
- 不得把缺失或落榜数据称为零。

## 截图规则

截图可以支持近似方向、标注的日期范围和显示的分类等可见事实。没有底层数据时，截图不能支持精确每日值、平均值、波动率或因果解释。
