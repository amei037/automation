# ASO 实验规划

设计能够隔离单一决策的测试，并说明现有流量能够支持什么结论。

## 前置条件

必须具备：

- 已验证的产品背景
- 要验证的决策或不确定性
- 平台、商店地区和用户
- 线上实验的对照组定义
- 仅在估算样本量或周期时需要的基线转化率和流量

没有基线数据时，建立假设清单和测量计划，不得虚构测试周期或置信度。

## 工作流程

1. 阅读 [experiment-policy.md](experiment-policy.md)。
2. 明确实验结果将改变的决策。
3. 写出可证伪的假设。
4. 选择一个主要变量，尽可能固定元数据、流量、价格、版本和其他素材。
5. 定义主指标、护栏指标、分群、归因窗口和污染风险。
6. 如果已知基线转化率和有业务意义的最小可检测差异，计算独立规划估算：

```bash
python3 scripts/estimate_sample_size.py --baseline 0.25 --relative-mde 0.10
```

7. 最终平台决策优先采用平台报告的实验分析，不得用规划估算覆盖平台结果。
8. 预先登记停止与决策规则。
9. 记录胜出、失败或无结论的结果以及下一步行动。

## 模式

- `pre-launch validation`：访谈、偏好或理解度检查、内部审核和信息测试；不得称为商店转化 A/B 测试。
- `live store experiment`：随机或平台管理的商店页面实验。
- `observational change`：没有随机化的前后对比；不得声称因果关系。
