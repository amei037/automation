# DEDC 品牌与视觉规范

权威来源：`dedc规范文件(2).pdf`

文档级别：内部 T1 品牌规范

规范更新时间：2026-07-21

## 1. Logo

- 使用规范文件中的原始 DEDC 椭圆 Logo，不重绘、不改字形、不改变内部比例。
- 标准用法：深蓝底、金色图形与文字。
- 允许的纯色/反白方向：深蓝、金、白、黑，必须保证对比度和可读性。
- 禁止使用规范外的填充色、低对比背景、发光/阴影改造、拉伸、压缩、旋转或拆分。
- `SINCE 2013` 是 Logo 组成部分；除非使用经过批准的独立变体，不得自行删除。

Logo 文件和批准变体优先于文字描述。无法取得原始资产时，不要让生成式模型重造 Logo。

## 2. 核心色

| 角色 | 色值 | 用法 |
|---|---|---|
| 品牌深蓝 | `#273B6C` | 标准品牌主色、Logo 背景、包装与品牌识别 |
| 品牌金 | `#E1C852` | Logo、标题强调、数据重点和细线 |
| 白 | `#FFFFFF` | 反白、浅色背景、深色背景正文 |
| 黑 | `#000000` | 黑白场景、正文和反白组合 |

只使用以上四色建立品牌识别。金色应作为强调色，不应大面积制造促销感。

### App/ASO 执行色

当前 ASO 暗色素材使用接近 `#081426` 的深海军蓝背景。它是已采用的应用背景色，不替代品牌规范中的主蓝 `#273B6C`：

- `#273B6C`：品牌标准蓝。
- `#081426`：App/商店素材的暗夜背景执行色。
- `#E1C852`：两种体系共同使用的品牌金。

## 3. 字体

| 层级 | 规范字体 |
|---|---|
| 主标题 | D-DIN Exp Bold |
| 副标题 | D-DIN Bold |
| 正文 | D-DIN |

当前 ASO 素材中 Inter 可用于小号说明文字和数据标签，但它是应用层补充字体，不替代品牌规范字体。

## 4. 视觉原则

- 关键词：权威、标准、秩序、信任、数据、精密、克制。
- App 与数字营销可使用“暗夜金”：深色背景、白色主体文字、金色数据重点。
- 包装与说明材料可使用“实验室白”：白底、深蓝文字、金色分隔和清晰图表。
- 优先真实 UI、真实结果界面、清晰数据结构和充分留白。
- 避免卡通化、促销化、霓虹化、复杂装饰和无依据的“实验室”视觉暗示。
- 不引入大红、大橙、荧光绿等促销色作为品牌主视觉。
- 不通过 Pokemon 等角色图像建立品牌资产；公开素材必须确认卡图/IP 使用授权。

## 5. 功能图标

PDF 中的 1.5 cm 图标尺寸与 6-8 pt 标签规则适用于包装/印刷示例，不应机械换算为 App 界面像素。数字界面应保留相同的线性、简洁和可读性原则，并遵守平台可访问性要求。

## 6. 视觉审核清单

- [ ] 使用批准的 Logo 文件或变体。
- [ ] Logo 未变形、重绘或改变颜色关系。
- [ ] 核心色来自批准色板。
- [ ] 品牌金为强调而非大面积促销底色。
- [ ] 标题与正文层级符合 D-DIN 体系。
- [ ] 真实 UI 与文案描述一致。
- [ ] 无未经证明的准确率、领先性、认证或官方关系。
- [ ] 无未经授权的第三方角色、卡牌或评级机构 Logo。
- [ ] AI 预评分与官方评级边界清晰。
