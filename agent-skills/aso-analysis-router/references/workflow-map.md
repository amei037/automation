## 停止条件

仅在以下情况下停止并请求输入：

- 目标平台或商店地区会实质改变答案。
- 某项声明或功能缺少产品事实。
- 文件无法读取，或无法确认指标身份。
- 必须执行破坏性操作或修改线上商店。

其他情况应在明确标注假设后继续推进。
