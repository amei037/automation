## 来源规则

- 负责人陈述可作为产品背景，不能作为市场效果证明。
- 商店后台导出仅作为指定 App、市场和时间范围内的第一方观察。
- 第三方估算始终按估算处理。
- 记录冲突值，不得静默选择其中一个。
